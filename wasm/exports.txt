# WASM exported functions for the document-collection layer in this
# package, one per line -- everything wasm/nisaba-wasm.js's Collection/Db
# classes call. Consumed by build-wasm.sh, which appends this list to
# -sEXPORTED_FUNCTIONS alongside binjson's _bjw_* codec symbols and
# third_party/binjson-structures/wasm/exports.txt.
#
# These symbols also carry EMSCRIPTEN_KEEPALIVE in db_wasm.c, which is
# what actually forces them into the binary; listing them here is the
# manifest that lets a consumer linking these sources into its own
# combined binary reproduce the surface without hand-mirroring it, and
# gives the export set one reviewable home instead of a heredoc.
#
# The native build (build-native.sh) ignores this file entirely: it links
# db.c and calls the dc_* internal API directly, with no JS ABI in
# between.
